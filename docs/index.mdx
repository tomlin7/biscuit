Welcome to Biscuit! Biscuit is designed to be a lightweight, ultra-fast alternative to bloated modern editors, built entirely on Python and Tkinter, powered by Tree-sitter for syntax intelligence, and packed with modern developer capabilities like Git integration, AI agents, extension marketplace, and debugging.

## Getting Started

To get started with Biscuit, you can install it using pip:

```bash
pip install biscuit-editor
```

Once installed, simply type `biscuit` followed by a file or folder path to open it:

```bash
biscuit .
```

For more options, check the [Quickstart](/quickstart) guide.
