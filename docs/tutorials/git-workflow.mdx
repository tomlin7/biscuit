Use Biscuit's built-in Git tools to manage a project end to end.

## 1. Clone a repository

1. Open the command palette (`Ctrl+Shift+P`).
2. Run **Git: Clone**.
3. Paste an HTTPS or SSH URL and choose a destination folder.

Biscuit opens the cloned folder as a workspace.

## 2. Make a change and view the diff

1. Edit any file.
2. Open the Source Control panel from the activity bar.
3. Click the file to see a side-by-side [Diff Viewer](/git-integration/diff-viewer).

## 3. Stage and commit

1. Click **+** next to a file to stage it.
2. Enter a commit message.
3. Press `Ctrl+Enter` to commit.

See [Basic Git Operations](/git-integration/basic-operations) for branching, pulling, and pushing.

## 4. Push and open a pull request

1. Push with the sync button in the status bar.
2. Open the [GitHub Integration](/git-integration/github) panel to browse issues and pull requests without leaving Biscuit.
