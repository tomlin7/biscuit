Make Biscuit feel like yours with themes, settings, and keybindings.

## 1. Switch the theme

1. Open the command palette (`Ctrl+Shift+P`).
2. Run **Preferences: Color Theme**.
3. Pick a theme from the list.

More detail in [Settings & Themes](/getting-started/settings-and-themes).

## 2. Edit settings

1. Open the command palette and run **Preferences: Open Settings**.
2. Adjust common options:

```json
{
  "editor.fontSize": 14,
  "editor.fontFamily": "JetBrains Mono",
  "editor.tabSize": 4,
  "editor.minimap": true,
  "editor.wordWrap": "on"
}
```

## 3. Try Vim mode (optional)

Enable modal editing:

```json
{
  "editor.vim": true
}
```

See [Vim Mode](/editor/vim-mode) for supported motions and commands.

## 4. Learn the shortcuts

Skim the [Keyboard Shortcuts](/keyboard-shortcuts) reference and pin the ones you use most.
