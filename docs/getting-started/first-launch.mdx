key areas. This guide walks you through each part.

## Opening a Project

There are several ways to open a project in Biscuit:

### Command Line

```bash
biscuit path/to/your/project
```

### From the Editor

1. Press `Ctrl+O` to open a file dialog
2. Press `Ctrl+Shift+O` to open a directory
3. Drag and drop a folder onto the editor window

### Clone from GitHub

1. Press `Ctrl+Shift+P` to open the command palette
2. Type `clone:` and press Enter
3. Enter the repository URL

## Command Palette

The command palette is your primary tool for navigation and actions:

| Prefix | Action |
|--------|--------|
| `> ` (empty) | Commands |
| `@` | Symbol search |
| `:` | Go to line |
| `active:` | Open editors |
| `recentf:` | Recent files |
| `recentd:` | Recent folders |
| `branch:` | Git branch switch |
| `clone:` | Clone repository |

Press `Ctrl+P` to open the palette, or `Ctrl+Shift+P` for file search.

## Sidebars

### Primary Sidebar (Left, `Ctrl+B`)

| Tab | Purpose |
|-----|---------|
| **Explorer** (`Ctrl+E`) | File tree navigation |
| **Search** (`Ctrl+F`) | Global search and replace |
| **Source Control** (`Ctrl+G`) | Git operations |
| **Debug** (`Ctrl+D`) | Debugger controls and variables |

### Secondary Sidebar (Right, `Ctrl+Shift+B`)

| Tab | Purpose |
|-----|---------|
| **Outline** (`Ctrl+J`) | Symbol outline of current file |
| **AI** (`Ctrl+A`) | AI coding assistant |
| **GitHub** | GitHub issues and pull requests |
| **Extensions** (`Ctrl+X`) | Extension marketplace |

## Status Bar

The status bar at the bottom shows:

- Current branch and git status (left)
- Language mode, encoding, line ending, indentation (right)
- Active editor path
- Background tasks and notifications
