## General

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New file |
| `Ctrl+Shift+N` | New window |
| `Ctrl+O` | Open file |
| `Ctrl+Shift+O` | Open directory |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+W` | Close file/editor |
| `Ctrl+Shift+W` | Close all editors |
| `Ctrl+Q` | Quit |
| `Ctrl+,` | Open settings |

## Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+Shift+T` | Restore closed tab |
| `Ctrl+\` | Split editor |
| `Ctrl+Shift+K` | Delete line |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+P` | Command palette |
| `Ctrl+Shift+P` | File search |
| `Ctrl+J` | Symbol outline |
| `Ctrl+G` | Go to line |
| `Ctrl+Tab` | Next tab |
| `Ctrl+Shift+Tab` | Previous tab |

## Multi-Cursor

| Shortcut | Action |
|----------|--------|
| `Ctrl+Alt+Up` | Add cursor above |
| `Ctrl+Alt+Down` | Add cursor below |
| `Ctrl+D` | Add cursor at next match |
| `Ctrl+U` | Undo last cursor |
| `Alt+Enter` | Select all matches |
