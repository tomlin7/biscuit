Biscuit includes built-in Git integration powered by **GitPython**. You can
perform common Git operations directly from the editor without switching to a
terminal.

## Git Panel

The Git panel is accessible via:

- **Primary Sidebar** → **Source Control** tab (`Ctrl+G`)
- Shows current repository status

### What You Can See

- **Changed files** — Modified, added, deleted, untracked, and staged files
- **File status icons**:
  - `M` — Modified
  - `A` — Added
  - `D` — Deleted
  - `U` — Untracked
  - Staged vs unstaged sections
- **Current branch** — Displayed in the status bar
- **Pending changes** — Number of uncommitted changes

## Repository Detection

Biscuit automatically detects Git repositories when you open a directory.
The status bar shows the current branch name and change count.
